# Live End-to-End Suite

This page compares claude-rs with the stock Claude Code TUI it runs on, one
functionality per row. It is generated by the live end-to-end suite in
`scripts/e2e-parity/`, which drives a real claude-rs build in a private tmux
server against the real, logged-in stock Claude Code and reads the screen, the
session registry (`claude agents --json`), transcripts and the files a turn
writes. Later features add their checks to the suite. Do not edit the tables by
hand; re-run the suite.

| Reading | Meaning |
| --- | --- |
| PASS | claude-rs does what stock Claude Code does. |
| **FAIL** | claude-rs attempts it but the result differs from stock. |
| **GAP** | Stock Claude Code has it; claude-rs does not (yet). |
| SKIP | Not exercised by the suite; the note says why. |

## Running the suite

Prerequisites: tmux, jq, node, bash 4 or later, a claude-rs build, and a
logged-in stock Claude Code binary (started directly, never through a launcher
that can route to claude-rs; override with `--claude` or `PARITY_CLAUDE_BIN`).
The login is per config directory on macOS, so pass a logged-in directory with
`--config-dir` or `PARITY_CONFIG_DIR`, or `--owner-profile` to use the current
profile (sessions still run in scratch directories). It is local and opt-in:
never run in CI, and it spends real model usage. Every turn uses Haiku unless
`--model` says otherwise; a full run costs about $0.45 (measured $0.43 to
$0.48 on 2026-10-12, most of it the plan-mode check, whose stock child plans on
Sonnet) and takes about 5 minutes, or about 15 with the performance group,
which only a release build runs. The run ends with the cost and warns above `PARITY_COST_BUDGET`
(default $0.60).

```sh
# The installed release (its bridge and runtime ship next to the binary):
scripts/e2e-parity/run.sh --config-dir "$PARITY_CONFIG_DIR" --report docs/src/parity.md

# A source build:
cargo build && npm run build --prefix agent-sdk
scripts/e2e-parity/run.sh --owner-profile --bin target/debug/claude-rs \
  --bridge agent-sdk/dist/bridge.js --report docs/src/parity.md

# One check, one group, or one check file:
scripts/e2e-parity/run.sh --only cmd.model
scripts/e2e-parity/run.sh --only 'agents.*'
scripts/e2e-parity/run.sh --only '10-*'
```

See `scripts/e2e-parity/README.md` for the options, the safety rules and how
cleanup works.
